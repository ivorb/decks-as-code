    This browser can't unzip in the page

    Importing needs DecompressionStream('deflate-raw'), which this browser does not provide. Use a current Chrome, Edge, Firefox or Safari, or run the command line version instead:

    This page needs a web server

    You opened it from your file system. Browsers refuse to load JavaScript modules over file://, so the converter cannot start.

    From the decks-as-code folder:
    python -m http.server 8000 --directory dist
    then open http://localhost:8000/import.html.

    Or skip the browser entirely: node tools/import-pptx.mjs talk.pptx --slug my-talk
