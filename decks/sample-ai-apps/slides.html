Microsoft Foundry

A unified platform for AI apps and agents

Foundry resources in Azure provide compute, storage, model delivery, and other services

Foundry projects are isolated work environments for app and agent development

In a project, you work with:

Models – choose and deploy models from an extensive model catalog

Agents – create and manage agents that use models for language and reasoning

Tools – connect agents to tools so they can perform actions and access information

Knowledge – manage data source access for agents so they have the information they need to act
