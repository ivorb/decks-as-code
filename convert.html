Convert a PowerPoint to HTML

Turns a .pptx into HTML slides with every piece of text kept as real, translatable text. The file is read here in your browser and never uploaded anywhere.

Drop a .pptx here or click to choose one

Converted

The single file opens by double-click. The folder holds slides.html, strings.json (every translatable string, with a stable ID) and images/; unzip it into decks/ and run node tools/build-manifest.mjs to publish it with the site.

    This browser can't unzip in the page

    Converting needs DecompressionStream('deflate-raw'), which this browser does not provide. Use a current Chrome, Edge, Firefox or Safari, or run node tools/pptx-to-html.mjs talk.pptx --slug my-talk instead.

    This page needs a web server

    Browsers refuse to load JavaScript modules over file://. From the decks-as-code folder:
    python -m http.server 8931, then open http://localhost:8931/convert.html.
